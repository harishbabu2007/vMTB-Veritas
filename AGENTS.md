# AGENTS.md

**vMTB Veritas** is a virtual Molecular Tumor Board platform: multidisciplinary oncology teams collaborate on cancer cases, review genomic profiles, and run structured case discussions, including live video MTB meetings with automatic transcription and AI-generated minutes. It's a monorepo consolidating what used to be three separate repositories (`main`, the Jitsi meeting services, and the transcription pipeline).

This file is intentionally short. The complete, current guidance for this repo — repo structure, commands, architecture, cloud services, git workflow — lives in the root **`CLAUDE.md`**, and every cross-cutting deep-dive doc (database schema, document-AI pipeline, meeting-transcription pipeline, deployment, local dev, known issues) lives under **`docs/`** (start at `docs/README.md`). Read those; this file is kept around only because some agentic tools look for `AGENTS.md` by convention.
